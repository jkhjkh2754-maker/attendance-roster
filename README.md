# 출석부 작업실

[웹앱 열기](https://jkhjkh2754-maker.github.io/attendance-roster/)

브라우저에서 제목·인원·명단을 설정하고 한글 출석부 PDF를 만드는 정적 웹앱입니다. 별도의 서버, 데이터베이스, AI API, 로그인 없이 작동합니다.

## 기본 출석부

- 제목, 전체 인원(1~300명), 시작 번호, 날짜(최대 31칸)·회차(최대 40칸)를 지정합니다.
- 연도와 월을 지정하면 요일을 자동으로 넣을 수 있습니다.
- A4 세로·가로, 페이지당 인원(5~40명), 색상, 학번·비고 칸을 선택합니다.
- 한 줄당 `0011 홍길동`, `0011, 홍길동` 또는 이름만 입력합니다. 엑셀의 두 열을 복사한 탭 구분 입력도 지원합니다.
- 입력 순서와 학번 앞자리 0을 보존합니다. 정원 초과·잘못된 명단은 오류로 안내하며 임의로 자르지 않습니다.
- 명단 없이 빈 양식을 생성할 수 있습니다. 설정 변경 후 업데이트 또는 PDF 저장을 누르세요.

## 나의 PDF 양식

1. PDF 양식(10MB 이하, 최대 15쪽)을 불러옵니다.
2. 이름 칸 버튼을 누른 뒤 미리보기에서 **첫 번째 사람의 칸** 왼쪽 위와 오른쪽 아래를 차례로 누릅니다.
3. 학번이 있다면 학번 칸도 같은 방식으로 지정합니다. 번호 칸은 원본에 번호가 없는 경우에만 지정합니다.
4. 원본의 첫 행과 다음 행의 간격을 pt 단위로 입력합니다. 처음 지정한 칸 높이와 행 간격은 별개입니다. 예덕반 원본은 24행, 행 간격 30pt입니다.
5. 페이지당 인원을 원본 행 수로 맞추고 미리보기를 업데이트합니다. 행 위치가 어긋나면 행 간격을 조절하거나 영역을 다시 지정합니다.
6. 제목을 바꾸려면 제목 영역을 별도로 지정합니다. 선택한 영역만 흰색으로 덮고 새 제목을 넣으므로 테두리와 겹치지 않도록 지정합니다.

첨부 양식은 표·날짜·기존 번호를 유지하고 지정한 칸에만 텍스트를 추가합니다. 기본 설정의 색상·용지 방향·날짜 칸 수·비고 칸은 첨부 양식을 재구성하지 않습니다. 여러 페이지의 양식에는 같은 상대 위치를 적용하므로 구조가 같은 페이지를 사용하세요. 추가 페이지가 필요하면 원본 페이지 순서대로 반복합니다. 원본 페이지 수는 줄이지 않습니다.

암호화된 파일, 페이지 회전이나 잘라내기 정보가 있는 PDF는 지원하지 않습니다. PDF로 인쇄하여 일반 페이지로 저장한 뒤 다시 불러오세요. 전자서명된 문서에는 사용하지 마세요. 기입 위치는 사용자가 미리보기로 확인해야 합니다. 저장되는 PDF에는 위치 지정용 초록색 영역 표시가 포함되지 않습니다.

## 개인정보와 비용

- 명단과 첨부 PDF는 브라우저 메모리에서만 처리합니다. 서버 업로드·분석·자동 저장·쿠키·사용자 추적 기능이 없습니다.
- 새로고침하면 입력과 첨부 자료가 사라집니다. 결과는 PDF로 직접 저장하세요.
- 코드·한글 글꼴·라이브러리만 GitHub Pages에서 내려받습니다. GitHub의 일반 접속 로그는 GitHub 정책을 따릅니다.
- 공개 저장소에는 **실제 학생 명단이나 완성 출석부를 올리지 마세요.** 공개 저장소와 공개 페이지는 누구나 접근할 수 있으며, 이 웹앱에는 20명만 접근하도록 제한하는 기능이 없습니다.
- 공개 GitHub 저장소 + GitHub Pages 기본 주소를 사용하며, AI API 호출이 없어 해당 API 비용이 발생하지 않습니다. 유료 도메인·유료 호스팅을 따로 연결하면 그 서비스 비용은 별개입니다.

## 실행 및 배포

빌드 단계가 없습니다. 저장소의 `main` 브랜치 루트를 GitHub Pages 게시 소스로 선택합니다. 웹앱은 HTTPS에서 실행하세요. 파일을 직접 여는 `file://` 실행은 지원하지 않습니다.

로컬 확인: 이 폴더에서 정적 HTTP 서버를 실행하고 브라우저로 접속합니다. 예: `python -m http.server 8080`.

최신 Chrome·Edge·Safari·Firefox를 대상으로 합니다. 모바일에서는 PDF 저장 버튼으로 다운로드 후 파일 앱이나 PDF 뷰어에서 인쇄하세요. 첨부 PDF의 비표준 용지·혼합 방향은 저장한 PDF의 뷰어에서 인쇄하는 편이 정확합니다.

- `core.mjs`: 입력 검증, 표 생성, 원본 PDF 복사 및 텍스트 기입

- PDF 표시: PDF.js / pdfjs-dist 5.4.624 (Apache-2.0), 평가 기능 비활성화
